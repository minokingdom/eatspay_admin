# Eats Pay Announcement Image News Design

## Goal

이츠페이 웹과 앱 웹뷰의 `이츠페이 알림장`을 이츠고의 `배달종사자 소식`과 같은 이미지 중심 소식 화면으로 개선한다. 홈과 전체 게시판의 번호를 일치시키고, 현재 운영 중인 알림장 20개 게시물에는 내용별 고유 이미지를 연결한다.

## Decisions

- 게시 번호는 데이터베이스 ID가 아니라 최신순 전체 게시물 수를 기준으로 표시한다.
- 현재 게시물이 20개이면 홈 최신 5개는 `20, 19, 18, 17, 16`으로 표시한다.
- 홈은 최신 5개만 표시하며 제목, 작성자, 날짜, 우측 썸네일을 한 행에 배치한다.
- 전체 목록은 5개 단위 페이지를 사용하고 각 행에 같은 이미지 썸네일을 표시한다.
- 상세 팝업은 제목, 대표 이미지, 작성자와 날짜, 본문, 조회와 관심 순서로 구성한다.
- 각 게시물은 대표 이미지 한 장을 사용한다. 저장 구조는 향후 확장을 위해 `image_urls` JSON 배열을 사용한다.
- 이미지가 없거나 로딩에 실패하면 이츠페이 로고 기반 기본 이미지를 표시한다.
- 루트 웹과 Capacitor 웹뷰의 HTML, CSS, JavaScript는 같은 동작을 유지한다.

## Image Direction

- 생성 방식: Codex 내장 ImageGen.
- 수량: 현재 알림장 20개에 게시물별 고유 이미지 20장.
- 스타일: 자연광 기반의 한국 소상공인 매장 운영, 세무 자료, 배달 운영을 다룬 현실적인 에디토리얼 사진.
- 비율: 목록 썸네일과 상세 크롭을 함께 지원하는 16:9 가로 이미지.
- 금지: 이미지 안의 글자, 워터마크, 실제 배달 플랫폼 로고, 과도한 연출, 식별 가능한 금융 개인정보.
- 파일명: `assets/announcements/announcement-<post-id>.webp`.

## Data Model

`board_posts`에 다음 필드를 추가한다.

```sql
image_urls JSONB NOT NULL DEFAULT '[]'::jsonb
```

서버 응답은 기존 클라이언트 관례와 호환되도록 아래 두 값을 제공한다.

- `imageUrls`: JavaScript 배열
- `image_urls`: 기존 이츠고형 렌더러와의 호환 배열

생성 및 수정 API는 `imageUrls` 또는 `image_urls`를 받아 검증된 로컬 업로드 URL만 저장한다.

## Admin Flow

알림장 작성 및 수정 모달에 `대표 이미지` 영역을 추가한다.

- 이미지 미리보기
- 파일 선택
- 붙여넣기
- 이미지 교체
- 이미지 삭제
- 저장 전 업로드 상태 표시

업로드 파일은 기존 서버 업로드 정책을 재사용하고 이미지 MIME 형식과 용량을 검증한다. 저장 실패 시 게시글 본문을 잃지 않고 구체적인 오류를 표시한다.

## Web Layout

### Home

- 섹션 제목과 `더보기`는 현재 위치를 유지한다.
- 행 높이는 고정하고 제목은 한 줄 말줄임 처리한다.
- 작성자와 날짜를 제목 아래에 표시한다.
- 우측에는 동일한 크기의 56px 썸네일을 표시한다.
- 최신 5개 번호는 전체 데이터의 최신순 인덱스를 사용한다.

### Full Board

- 한 페이지에 5개를 표시한다.
- 페이지 이동 후에도 번호는 전체 20개 기준으로 감소한다.
- 제목, 작성자, 날짜, 조회, 관심, 썸네일을 안정된 열 구조로 표시한다.

### Detail

- 기존 공통 앱 모달을 사용한다.
- 대표 이미지는 제목 아래, 메타 정보 위에 16:9로 표시한다.
- 본문 줄바꿈을 보존한다.
- 조회 및 관심 동작은 기존 API를 그대로 사용한다.

## Error Handling

- 이미지 URL이 없으면 기본 이미지를 사용한다.
- 이미지 로딩 오류 시 한 번만 기본 이미지로 교체한다.
- 이미지 업로드 실패는 게시글 저장과 구분해 안내한다.
- 기존 이미지 없는 게시물도 스키마 변경 직후 정상 렌더링되어야 한다.

## Verification

- 홈 최신 5개 번호가 전체 목록 첫 페이지 번호와 일치한다.
- 전체 목록이 5개 단위로 페이지 이동하며 번호가 연속된다.
- 20개 게시물 모두 서로 다른 대표 이미지를 반환한다.
- 홈 썸네일과 상세 이미지가 같은 게시물 이미지를 사용한다.
- 이미지가 없는 응답과 깨진 URL에서 기본 이미지가 표시된다.
- 루트 웹과 `www` 웹뷰 모두 동일한 계약 테스트를 통과한다.
- 관리자 이미지 선택, 붙여넣기, 교체, 삭제와 저장을 브라우저에서 확인한다.
- 운영 배포 후 `eatspay.kr`에서 홈, 전체 목록, 상세 팝업을 모바일 폭으로 확인한다.
