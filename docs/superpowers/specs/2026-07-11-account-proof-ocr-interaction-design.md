# 계좌 증빙 OCR 이미지 조작 개선 설계

## 목표

관리자가 증빙 이미지를 확대하고 위치를 맞춘 뒤 계좌번호 영역을 자연스럽게 선택하도록, 이미지 이동과 사각형 선택 조작을 명확히 분리한다.

## 조작 흐름

1. `계좌번호 자동 인식`을 누르면 증빙 화면이 열리고 `이동·확대` 모드로 시작한다.
2. PC에서는 휠 또는 `− / + / 100%` 버튼으로 확대·축소하고, 드래그로 이미지를 이동한다.
3. 모바일에서는 두 손가락으로 확대·축소하고 한 손가락으로 이미지를 이동한다.
4. 관리자가 `계좌 영역 선택`을 누르면 선택 모드로 전환한다.
5. 선택 모드에서는 드래그가 사각형 선택에만 사용되며 화면 안내와 커서가 함께 바뀐다.
6. 영역을 그리면 `이 영역 인식하기`, `다시 선택`, `이동·확대로 돌아가기`를 제공한다.
7. OCR 실행 후에는 기존 일치, 불일치, 인식 실패 결과를 계좌 확인 카드에 표시한다.

## 좌표와 상태

- 선택 영역은 화면 좌표가 아니라 표시된 이미지의 정규화 좌표로 저장한다.
- 확대율이나 스크롤 위치가 달라도 서버로 전달되는 선택 영역은 원본 이미지 기준으로 유지한다.
- 모드 전환, 다시 선택, 창 닫기 시 선택 상자와 임시 버튼 위치를 일관되게 초기화한다.
- 선택 모드에서 이미지 이동이 실행되지 않고, 이동 모드에서 선택 상자가 생성되지 않아야 한다.

## 계좌 확인 카드 배치

- 중복 기능인 `증빙 크게 보기` 버튼은 제거한다.
- 첫째 줄: `계좌번호 복사`와 `계좌번호 자동 인식`을 나란히 배치한다. 자동 인식 버튼은 삭제된 `증빙 크게 보기`의 자리를 사용한다.
- OCR 결과 안내는 버튼 아래에서 긴 한 줄이 되지 않도록 두 줄의 짧은 문장으로 표시한다.
- 모바일에서도 두 버튼의 나란한 배치와 결과 안내의 두 줄 구조를 유지한다.

## 오류 처리

- 선택 영역이 너무 작거나 없으면 OCR 요청을 보내지 않고 다시 선택하도록 안내한다.
- 이미지 로드 실패, OCR 실패, 불일치는 기존 승인 상태를 변경하지 않는다.
- 오류 안내가 조작 버튼을 밀어내거나 가리지 않도록 카드 안에서 별도 결과 영역을 유지한다.

## 검증

- 이동 모드에서 확대, 축소, 100% 초기화, 드래그 이동을 검사한다.
- 선택 모드에서 사각형 생성, 다시 선택, OCR 실행, 이동 모드 복귀를 검사한다.
- 확대·이동 후 선택한 정규화 좌표가 올바르게 전달되는지 검사한다.
- 모바일 포인터 조작, 두 버튼의 나란한 배치, 결과 안내의 두 줄 표시를 검사한다.
- 기존 OCR API 및 일치 판정 회귀 테스트를 함께 실행한다.

## 범위

관리자 계좌 증빙 확인 화면과 관련 테스트만 수정한다. 홈페이지 히어로, 웹앱, 계좌 승인 규칙 및 OCR 서버 판정 로직은 변경하지 않는다.
