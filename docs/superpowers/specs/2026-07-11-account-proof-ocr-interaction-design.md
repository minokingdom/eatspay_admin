# 계좌 증빙 OCR 이미지 조작 개선 설계

## 목표

관리자가 증빙 이미지를 확대하고 위치를 맞춘 뒤 계좌번호 영역을 자연스럽게 선택하도록, 이미지 이동과 사각형 선택 조작을 명확히 분리한다.

## 조작 흐름

1. `계좌번호 자동 인식`을 누르면 증빙 화면이 열리고 `이동·확대` 모드로 시작한다.
2. PC에서는 휠 또는 `− / + / 100%` 버튼으로 확대·축소하고, 드래그로 이미지를 이동한다.
3. 모바일에서는 두 손가락으로 확대·축소하고 한 손가락으로 이미지를 이동한다.
4. 관리자가 `계좌 영역 선택`을 누르면 선택 모드로 전환한다.
5. 선택 모드에서는 드래그가 사각형 선택에만 사용되며 화면 안내와 커서가 함께 바뀐다.
6. 영역을 그리면 `이 영역 인식하기`, `다시 선택`, `이동·확대로 돌아가기`를 제공한다.
7. OCR 실행 후에는 기존 일치, 불일치, 인식 실패 결과를 계좌 확인 카드에 표시한다.

## 빠른 모드 전환

- 증빙 이미지 영역에서 마우스 오른쪽 버튼을 누르면 `이동·확대`와 `계좌 영역 선택` 모드가 서로 전환된다.
- 우클릭 전환 시 상단 모드 버튼의 활성 상태, 안내 문구, 이미지 커서를 동시에 갱신한다.
- 우클릭 직후 커서 옆에 현재 모드를 알리는 초록색 툴팁을 표시하고 1.2초 후 페이드아웃한다.
- 툴팁 문구는 `오른쪽 마우스 · 영역 선택 모드` 또는 `오른쪽 마우스 · 이동·확대 모드`이며 화면 가장자리에서 잘리지 않는다.
- 증빙 이미지 영역에서는 브라우저 기본 컨텍스트 메뉴를 표시하지 않는다.
- 왼쪽 버튼 드래그는 현재 모드에 따라 이미지 이동 또는 사각형 선택만 수행한다.
- 모바일과 키보드 사용자는 기존 상단 모드 버튼을 사용한다.

## 모바일 조작

- 모바일에서는 화면 아래에 `사진 이동`과 `영역 선택`을 제공하는 큰 고정 전환바를 표시한다.
- 이미지 위를 한 손가락으로 0.5초 동안 10px 이상 움직이지 않고 누르면 두 모드가 전환된다.
- 길게 누르기 전환 시 짧은 진동과 터치 위치 근처 모드 툴팁을 제공한다.
- 손가락이 10px 이상 움직이거나 두 번째 손가락이 닿으면 길게 누르기를 취소한다.
- 두 번째 손가락이 닿는 즉시 진행 중인 한 손가락 이동과 선택을 취소하고, 두 손가락이 모두 떨어질 때까지 한 손가락 이동을 다시 시작하지 않는다.
- 두 손가락 확대는 두 손가락의 가운데 지점을 확대 중심으로 고정하고 스크롤 위치를 보정해 사진이 튀지 않게 한다.
- 두 손가락 확대는 이동·확대 모드와 영역 선택 모드 모두에서 사용할 수 있다.

## 좌표와 상태

- 선택 영역은 화면 좌표가 아니라 표시된 이미지의 정규화 좌표로 저장한다.
- 확대율이나 스크롤 위치가 달라도 서버로 전달되는 선택 영역은 원본 이미지 기준으로 유지한다.
- 모드 전환, 다시 선택, 창 닫기 시 선택 상자와 임시 버튼 위치를 일관되게 초기화한다.
- 선택 모드에서 이미지 이동이 실행되지 않고, 이동 모드에서 선택 상자가 생성되지 않아야 한다.

## 계좌 확인 카드 배치

- 중복 기능인 `증빙 크게 보기` 버튼은 제거한다.
- 첫째 줄: `계좌번호 복사`와 `계좌번호 자동 인식`을 나란히 배치한다. 자동 인식 버튼은 삭제된 `증빙 크게 보기`의 자리를 사용한다.
- OCR 결과 안내는 버튼 아래에서 긴 한 줄이 되지 않도록 두 줄의 짧은 문장으로 표시한다.
- 인식 실패 안내는 `계좌번호를 인식하지 못했습니다.`와 `증빙을 직접 확인하세요.`를 명시적으로 줄바꿈해 정확히 두 줄로 표시한다.
- 일치 결과는 초록색, 불일치 결과는 빨간색 테두리와 바깥 광채가 약 1.4초 동안 2회 강조된 뒤 정지한다.
- 결과 상태가 새로 설정될 때마다 강조 애니메이션을 다시 시작하며 `prefers-reduced-motion`에서는 정적인 색상만 표시한다.
- 모바일에서도 두 버튼의 나란한 배치와 결과 안내의 두 줄 구조를 유지한다.

## 선택 영역 미리보기

- 계좌 확인 카드의 남는 공간에 `선택한 계좌 영역` 미리보기를 표시한다.
- 선택 영역 확정 시 브라우저 Canvas로 원본 증빙에서 해당 영역을 잘라 즉시 표시한다.
- 미리보기는 카드 너비에 맞춰 확대하되 원본 비율을 유지하고 찌그러뜨리지 않는다.
- OCR 성공, 불일치, 인식 실패 이후에도 현재 미리보기를 유지한다.
- 다시 선택하면 기존 미리보기를 새 영역으로 교체하고, 계좌 확인 모달을 닫으면 제거한다.
- 서버에 별도 잘라낸 이미지 파일을 저장하지 않는다.
- OCR 서버는 인식 숫자 문자열과 함께 각 숫자의 선택 영역 기준 정규화 좌표를 반환한다.
- 캡처 미리보기에서는 각 원본 숫자 바로 위에 해당 OCR 숫자를 한 자리씩 배치한다.
- 등록 번호와 같은 자리는 초록색, 다른 자리는 빨간색으로 표시하고 인식하지 못한 자리는 `?`로 표시한다.
- 사진 확대·축소와 무관하게 Canvas 표시 크기에 맞춰 정규화 좌표를 변환한다.
- 문자 좌표가 불완전하거나 신뢰할 수 없으면 잘못된 위치에 표시하지 않고 `위치 인식 실패`를 표시한다.
- 다시 영역을 선택하면 이전 문자 오버레이를 제거하고 새 OCR 결과로 교체한다.

## 오류 처리

- 선택 영역이 너무 작거나 없으면 OCR 요청을 보내지 않고 다시 선택하도록 안내한다.
- 이미지 로드 실패, OCR 실패, 불일치는 기존 승인 상태를 변경하지 않는다.
- 오류 안내가 조작 버튼을 밀어내거나 가리지 않도록 카드 안에서 별도 결과 영역을 유지한다.

## 검증

- 이동 모드에서 확대, 축소, 100% 초기화, 드래그 이동을 검사한다.
- 선택 모드에서 사각형 생성, 다시 선택, OCR 실행, 이동 모드 복귀를 검사한다.
- 확대·이동 후 선택한 정규화 좌표가 올바르게 전달되는지 검사한다.
- 모바일 포인터 조작, 두 버튼의 나란한 배치, 결과 안내의 두 줄 표시를 검사한다.
- 이미지 영역 우클릭이 모드를 전환하고 기본 컨텍스트 메뉴를 차단하는지 검사한다.
- 선택 좌표로 Canvas 미리보기를 생성하고 다시 선택 시 교체하는지 검사한다.
- 기존 OCR API 및 일치 판정 회귀 테스트를 함께 실행한다.

## 범위

관리자 계좌 증빙 확인 화면과 관련 테스트만 수정한다. 홈페이지 히어로, 웹앱, 계좌 승인 규칙 및 OCR 서버 판정 로직은 변경하지 않는다.
