# 디자인 스튜디오 레퍼런스 분석

## 목적

레퍼런스를 곧바로 이미지 생성에 넘기지 않는다. AI가 무엇을 읽었는지 편집 가능한 프롬프트로 먼저 공개하고, 사용자가 피사체·문구·로고·크기를 수정한 뒤 생성한다.

## 입력 순서

1. 레퍼런스 이미지 붙여넣기/업로드 또는 Pinterest·Variant 공개 URL 입력
2. 원본 미디어 유형 판별: 이미지, GIF, 영상, 공개 웹 미리보기
3. 원본 가로·세로와 영상 길이 확인
4. AI 분석 프롬프트 표시
5. 사용자가 분석 프롬프트와 출력 크기 수정
6. 별도 로고 업로드
7. 이미지 또는 모션 생성

## 분석 프롬프트

분석에는 구도, 카메라 시점, 피사체, 색상 역할, 실사/일러스트 매체, 타이포그래피, 로고 위치, 여백, 질감, 금지 요소를 포함한다. 영상은 핵심 프레임을 추출해 장면 순서, 전환, 카메라·오브젝트·텍스트 모션, 리듬과 반복 구간을 추가한다. 관찰하지 못한 움직임은 추측하지 않고 `확인 불가`로 표시한다.

`A · 가까운 스타일` 같은 고정 유사도 표현은 사용하지 않는다. 생성 후 실제 비교 점수가 없는 결과는 `레퍼런스 문법`처럼 방향만 설명한다.

## 크기

URL에서 확인한 원본 크기를 출력 크기의 초기값으로 사용한다. 사용자는 320~4096px 범위에서 가로·세로를 변경할 수 있다. 크기를 변경해도 분석 프롬프트는 유지한다.

## 로고

로고는 레퍼런스와 별도 파일로 받는다. 생성 지시에는 로고의 모양, 글자, 비율, 색상을 바꾸지 말고 분석 프롬프트에 지정한 위치에 배치하도록 명시한다. 타사 로고는 사용하지 않는다.

## 외부 URL

- Pinterest: 공개 핀의 대표 이미지, 영상 메타데이터와 핵심 프레임 분석
- Variant: 공개 페이지의 Open Graph 미리보기 분석. 로그인 전용 화면은 캡처 또는 내보낸 이미지가 필요
- Variant 웹 UI 탐색: 디자인 스튜디오에서 `Variant에서 시안 탐색`을 눌러 외부 도구에서 여러 시안을 비교한다. 선택한 시안은 캡처 후 디자인 스튜디오에 `Ctrl+V`로 붙여 넣어 분석한다. 영상의 실제 흐름처럼 Variant는 디자인 탐색, Codex는 EatsPay 코드와 이미지 구현을 담당한다.
- iframe은 사용하지 않는다. 교차 출처 정책 때문에 공식 API 또는 `postMessage`가 없으면 결과를 자동으로 읽거나 적용할 수 없고, 영상에서도 iframe이 아니라 Variant에서 고른 디자인을 코드 구현 도구로 넘기는 방식을 사용한다.

## 결과 확인

생성 결과는 새 창을 열지 않는다. 스튜디오 내부 큰 미리보기에서 휠 확대·축소, 드래그 이동, 화면 맞춤, 원본 크기, 캔버스 적용을 제공한다. 영상도 같은 미리보기에서 재생한다.
